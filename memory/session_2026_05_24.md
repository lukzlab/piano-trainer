## Ce qui a été construit cette session

### Practice Mode — refonte complète

Le panel practice (`.practice-overlay`, `position:fixed;right:0;width:var(--rp-width)`) est devenu le hub central de travail. Il s'adapte dynamiquement à la largeur du panneau droit (CSS var `--rp-width` mise à jour au resize et à l'ouverture).

**Contenu du panel practice (de haut en bas) :**
1. Bouton Fermer
2. Titre (gamme ou nom du morceau)
3. Nom de section
4. Affichage accord : prev / **current** / next
5. **Ligne d'enrichissements** (Maj/Maj7/add9/… ou Min/Min7/… selon type)
6. Indicateur de beat
7. Contrôles : BPM −/+ · Play/Pause · Mesure −/+
8. Prog dots (position dans la séquence)
9. **Section Séquence** : pills drag&drop pour réordonner, ✕ retirer, ↺ reset
10. **Section Outils** : toggle métronome + volume, style select, bouton Backing Track
11. **Section YouTube** (si backing track actif) : iframe + titre + "⟳ Autres vidéos" + picker 5 résultats

**Comportements clés :**
- Ouverture → `_setPianoMode('accord')` + piano affiche l'accord courant
- Fermeture → `_setPianoMode('gamme')` + piano nettoyé
- Changement d'accord → piano et COF se synchronisent automatiquement
- Changement gamme/tonique sur la roue → rebuild de la séquence si source ≠ 'song'

### Top bar → practice (masquage)

Quand practice est ouvert : `body:has(.practice-overlay.open) #atb-left{display:none}` masque le bloc gauche de la top bar (play, BPM, métronome, style, BT). Ces contrôles sont maintenant dans le panel practice.

Sync bidirectionnelle : les deux sélecteurs de style, les deux sliders de volume metro, les deux boutons metro restent alignés via `querySelectorAll('.metro-btn-all')` et `ytSetStyleSelect()`.

### Backing Track YouTube — intégré dans practice

- Embed iframe dans `#practice-yt-section` (plus de floating panel)
- Pause/resume via `postMessage({event:'command',func:'pauseVideo'})` sur fermeture/réouverture
- Recherche basée sur : root + genre + style + BPM + time sig (3/4, 6/8, 2/4 si ≠ 4/4)
- `_ytSearchCtx` sauvegarde le contexte pour "Autres vidéos"
- Bouton **"⟳ Autres vidéos"** : 5 requêtes parallèles (variants), picker de titres cliquables, toggle

**Styles disponibles :** Pad, Jazz, Bossa, Funk, Rock, Blues, Latin, R&B, **Drums** (ajouté cette session)

**Mapping YT complet** (`_ytBackingStyles`) : tous les styles ont maintenant une valeur (avant rock/blues/latin/rnb retournaient undefined).

### Drag COF → practice (Pointer Events)

- `pointerdown` sur n'importe quel segment de la roue (anneau maj + min)
- Ghost div coloré suit le curseur/doigt (`transform:translate(-50%,-60%)`)
- `setPointerCapture` → tracking continu hors de l'élément source
- `touch-action:none` sur `#cof` → pas d'interférence scroll tablette
- Seuil 8px : tap = changement de gamme (comportement d'origine), drag = ajout à la séquence
- Drop n'importe où dans `#practice-overlay` → `_practiceState.chords.push(chord)`
- Click annulé proprement via listener capturing one-shot

### Enrichissements practice ↔ piano (bidirectionnel)

- `_getActiveChord()` retourne en priorité le contexte practice si le panel est ouvert
- `_setPianoEnrich(eid)` gère le cas `mode:'practice'` : met à jour `ch.enrich`, `ch.label`, `ch.midis`
- `_practiceBuildEnrich()` : reconstruit la ligne d'enrichissements dans le panel
- `_practiceBuildSeq()` : les pills reflètent le label enrichi (ex. "Am7")
- `_practiceChordLabel(semi, type, eid)` : calcule le label avec ou sans enrichissement

### Séquence éditable

- `_practiceState.allChords` : snapshot original pour le reset
- Pills drag&drop HTML5 natif sur les accords de la séquence
- Retirer un accord (✕), réordonner (glisser), reset (↺)
- `_practiceRebuildIfOpen()` : rebuild auto sur changement de gamme/tonique

### Date GitHub dans la top bar

`#topbar-update` : `"dernière MAJ à: jj/mm/aa hh:mm"` en vert `#4caf82`.
Cache localStorage (`gh_update_date`) → s'affiche immédiatement même si l'API GitHub est rate-limitée.
Guard `Array.isArray(data)` → pas de crash si l'API retourne un objet erreur.
